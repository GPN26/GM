# Newspaper scans

This directory is intentionally empty. The website currently shows original headline references and links to the publishers, not copies of copyrighted articles.

If you have permission to publish a newspaper scan, save it here and add to that grandmaster record:

```js
"clipping": {"src": "assets/clippings/your-filename.webp", "alt": "Description of newspaper clipping", "credit": "Paper · date", "permission": "Reproduced with permission"}
```

On the website, an actual scan (when present) replaces that player's typeset headline preview.
